# AZURK — Ultimate Diwali Universe 2026 🪔

A standalone static, mobile-friendly Diwali surprise website for Azurk's friends. Works offline once downloaded. The optional Google fonts load only when an internet connection is available; fallback fonts work offline.

## Features
- Original five supplied profile photos: Azurk, Celestia, Sneha Kumari, Starky, Kai Hiwatari
- Personalized messages, gift surprises and fireworks
- Interactive Diya Dash tapping game with best score saved locally
- Generated festive background music and sound effects via Web Audio API (no third-party copyrighted audio)
- Share action when hosted via HTTPS
- Responsive layout, keyboard-accessible buttons and reduced-motion handling

## Run
Open `index.html` in a browser. For full features, serve the folder with a local HTTP server or host using GitHub Pages. On mobile, open in Chrome; tap **MUSIC OFF** to enable audio (browsers require interaction).

## Publish on GitHub Pages
1. Create a new **public** repository on GitHub, e.g. `azurk-diwali-universe`.
2. Upload `index.html` and the entire `assets` folder to the repository root, or upload all files using git.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)` and Save.
4. Your website will typically be `https://YOUR_USERNAME.github.io/azurk-diwali-universe/` once GitHub Pages reports deployment complete.

### Privacy
**IMPORTANT:** This package includes actual profile photographs shared for this project. Publishing a public GitHub repo or public GitHub Pages website makes them publicly available. Obtain permission from each person before publishing, or replace their photo files with avatar art. GitHub Pages on a public repository is not private.

No account, analytics, ads, tracking, backend or payment functionality is included. All gameplay stays in-browser.
